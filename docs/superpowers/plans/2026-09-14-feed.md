# Feed Implementation Plan

**Goal:** Implement requirement 1 from SekaiFeedModeration/ARCH.md.
**Architecture:** Combine-derived feed metadata feeds a UIKit diffable pager. A serialized playback coordinator controls a bounded WebKit window.
**Tech Stack:** SwiftUI, UIKit, Combine, WebKit, XCTest; iOS/iPadOS 15.
**Spec:** SekaiFeedModeration/ARCH.md

- [ ] Foundation: add Sekai wire decoding, injected feed API and visibility publisher; test ordered deduplication, raw-page cursor/terminal rules, retry and bounded hidden-page scanning. Configure iOS 15 and local ATS.
- [ ] Playback: add an independently testable serialized coordinator; test delayed pause/play, target changes, failures and inactivity. Implement generation-scoped WebKit slots, release on uncertain commands, retry and termination recovery.
- [ ] Pager: vertical viewport cells, stable snapshots and selection, settled-only playback, rotation recentering, near-end events, memory warning neighbor eviction, lifecycle suspension and lightweight error UI.
- [ ] Integrate root SwiftUI loading/error/load-more states. Build and run focused tests, simulator feed checks and an early frame measurement. Record limitations and run instructions.
